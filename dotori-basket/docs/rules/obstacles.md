# 방해물

> 정본은 `game/config/items.ts`(나뭇가지·돌멩이)와 `game/config/crow.ts`(까마귀)다.

## ⭐ 페널티가 갈린다 — 그래도 판단 부담은 안 오른다

| | 종류 | 받으면 | 해금 | weight |
|---|---|---|---|---|
| 🪵 나뭇가지 | 낙하물 | **콤보만 끊긴다** (체력 유지) | Lv3 | 6 |
| 🪨 돌멩이 | 낙하물 | **체력 −2** + 0.8초 무적 | Lv5 | 4 |
| 🐦‍⬛ 까마귀 | **이벤트** | 예고 후 화면의 과일을 먹는다 | Lv8 | — |

「밀도는 올리면서 판단 부담은 안 올린다」(`rules/items.md`)가 깨지지 않는 이유는
**셋 다 정답 행동이 "피한다"로 같기 때문**이다. 플레이 중에 "이건 어느 방해물이지"를
판단할 일이 없고, 차이는 **실패했을 때만** 드러난다.

이전에는 둘 다 체력 −1이라 **그림만 다른 같은 물체**였다. 종류를 늘려도 게임이 안 바뀌었다.

## ⭐ 최대 체력이 5인 이유

돌멩이가 2칸을 먹는다. 최대 3이면 **두 번에 죽어** 허용 실수 횟수가 급격히 준다.
5로 올리면 오답 과일 기준 관대함은 오히려 늘고, **돌멩이만 개별적으로 무서워진다.**

## ⭐ `weight` 는 방해물에만 읽는다

`pickDef` 가 균등 추첨이면 **절반이 체력 −2짜리**가 된다. 가중 추첨으로 나뭇가지를 더 자주 낸다.

⚠️ 과일의 `weight` 값은 폐기된 Phase 2(무게 → 낙하속도)의 잔재이고 아무도 읽지 않는다.
아이템별 낙하속도는 채택 불가다(아래).

## ⭐ 까마귀는 낙하물이 아니라 이벤트다

「과일을 먹어치운다」는 **받는 물건이 아니라는 뜻**이다. 스포너에 넣을 이유가 없고,
빼는 순간 걸림돌이 전부 사라진다.

| 낙하물로 넣었다면 | 이벤트라서 |
|---|---|
| `crossAt` 이 `pickDef` 보다 먼저 계산돼 아이템별 속도가 통과 시각을 거짓으로 만든다 | `planSpawn` 을 타지 않는다 |
| 레인 이동이 `laneGap` 보장을 깬다 | 레인에 묶이지 않는다 |
| 불변식 1(위치 보간 금지) | **적용 대상이 아니다** — 판정선을 지나는 *받는 물건*의 규칙이다. 그래서 가로로 날 수 있다 |
| 방해물 3종이 되어 기존 2종이 각 −33% | 방해물 풀 밖이다 |

### 흐름

```
대기 ──(dt)──> 예고(warn) ──> 비행 진입 순간에 먹는다(fly) ──> 대기
                 ↑ 노린 과일에 표식. 여기서 "뺏기기 전에 잡자"가 생긴다
```

⚠️ 잔여 시간은 **전부 dt 누적**이다. 벽시계로 두면 일시정지·해금 카드 동안 타 버린다.

### ⭐ 예고가 없으면 게임이 아니다

`warningSec: 0` 이면 플레이어가 개입할 수 없는 **순수 RNG 손실**이 된다.
1초의 예고가 까마귀를 위협에서 *순간의 긴장*으로 바꾼다.

### 무엇을 먹나 — 판정선에 가까운 과일부터

완전 랜덤이면 오답 과일을 치워주는 경우가 절반이라 **이득/손해가 반반**이 된다.
곧 받을 것부터 고르면 "노린다"는 느낌 없이 결과만 위협적이다.
**방해물은 먹지 않는다** — 치워주면 도움이 되어 버린다.
먹을 게 없으면 등장 자체를 미룬다(빈 화면에 날아오지 않는다).

## 채택하지 않은 것

| | 왜 |
|---|---|
| 아이템별 낙하 속도 | `spawner.ts` 가 `crossAt` 을 `pickDef` **보다 먼저** 계산한다. 기록된 통과 시각이 거짓이 되어 동시통과 상한이 무너진다. `fallSpeedMax` clamp 도 레벨 배율에만 걸려 무한 구간에서 회피여유가 0.02초가 된다 |
| 낙하 중 레인 변경 | `laneGap` 이 깨진다. 동시통과 상한은 레인과 무관하므로 실제 피해는 1개 규칙이지만, 얻는 재미 대비 비싸다 |
| 썩은 과일 | **판단형 방해물**이라 원칙을 정면으로 어긴다. 과일처럼 생긴 걸 골라내야 해서 눈 피로를 직접 악화시킨다 |
| 플레이어 레인을 노리는 배치 | 기술적으로 안전하지만(배치 규칙이라 `crossAt` 무관) 난이도가 올라간다. 필요해지면 `obstacleSeeksPlayerRatio` 로 연다 |
