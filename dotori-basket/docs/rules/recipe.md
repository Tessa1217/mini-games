# 레시피 · 판정 · 제한시간

## 4. 게임 규칙

### 4-1. 레시피 큐

HUD 상단에 `🍓 → 🍎 → 🍊`. 맨 앞이 현재 타깃(하이라이트 + 펄스).
받으면 체크 → 다음. 전부 채우면 완성 보너스 → 새 레시피.
생성 시 현재 해금된 과일 중에서만 뽑고, 같은 과일이 연속 2회 이상 나오지 않게 한다.

### 4-2. 판정 3종

| 상황 | 결과 |
|---|---|
| **정답** 획득 | +점수 × 콤보배율, 레시피 1칸 진행 |
| **오답** 획득 | **HP −1**, 콤보 리셋, 0.8초 무적, 과일 튕겨나가며 소멸. **레시피 진행·타이머는 유지** |
| **놓침** | **페널티 없음** (콤보도 유지). 노브: `hp.missPenaltyHp`, 기본 0 |

설계 원칙: **개별 실수는 용서하고, 전체 정체만 처벌한다.**
동시 낙하 구조에서 "오답을 피하느라 정답을 못 받는" 건 정상 플레이의 일부이므로 놓침은 무페널티로 두고,
대신 아래 레시피 타이머가 전역 압박을 담당한다.

### 4-3. ⭐ 레시피 제한시간

**목적 두 가지**
1. 아무것도 안 받고 버티는 플레이 차단 (빈 레인으로 회피만 하는 경우 포함)
2. 놓침 무페널티로 느슨해진 긴장감 회복

**규칙**
- 새 레시피 생성 시 타이머 시작, HUD에 게이지 바로 표시
- 만료 시 → **HP −1 + 레시피 재생성 + 콤보 리셋** (확정)
- 오답을 받아도 타이머는 리셋되지 않음 (레시피 진행이 유지되므로 일관)
- 레벨업 배너·일시정지 동안에는 타이머 정지
- 잔여 25% 또는 4초 이하에서 **경고 상태** (게이지 적색 + 펄스)

**시간 배분** ⚠️
```
제한시간 = 레시피 길이 × 항목당 시간
항목당 시간: Lv1 8.0s → 레벨마다 −0.3s → 하한 5.0s
예) Lv1(길이2) 16.0s · Lv4(길이3) 21.3s · Lv7(길이5) **31.0s**
```
정상 플레이에서는 거의 걸리지 않고, **의도적으로 안 받을 때만** 걸리는 수준으로 잡는다.
타이머가 상시 압박이 되면 "피하는 판단"이라는 이 게임의 핵심이 죽는다.
