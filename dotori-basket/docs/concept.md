# 컨셉과 확정 사항

## 0. 확정 사항

| 항목 | 결정 |
|---|---|
| 순서 표시 | **레시피 큐** (다음 N개 미리보기) |
| 낙하 구조 | **레인 기반** — 5 레인 고정, 레인당 하나씩, 시작 시점이 다르게 동시 낙하 |
| 레인 수 | **5 고정** — 레벨이 올라도 바뀌지 않음 |
| 다람쥐 위치 | **레인 인덱스(이산값)**. 위치는 즉시 스냅 — **위치 보간을 하지 않는다**(`rules/lane.md`) |
| 이동 게이트 | 탭·홀드·키보드가 **모두 `moveCooldownMs` 하나를 통과**(`rules/lane.md`) |
| 획득 판정 | **자기 레인에 떨어지는 과일만** 받음 |
| 오답 처리 | **HP −1**, 레시피 진행은 **유지**, 과일은 튕겨나가며 소멸 |
| 놓침 처리 | **페널티 없음** (개별 실수는 용서 — 전체 정체는 타이머가 처벌) |
| 정체 방지 | **레시피 제한시간** 도입 — 만료 시 **HP −1 + 레시피 재생성** |
| 방해물 | **돌멩이 · 나뭇가지** 2종, Phase 1 포함 |
| 난이도 축 | 과일 종류 · 오답 비율 · 낙하 속도 · **스폰 간격(밀도)** · 방해물 드롭률 |
| HP 회복 | **없음** — 종료 조건이 HP뿐이므로 회복을 두면 세션이 끝나지 않는다(`rules/hp-score.md`) |
| 조작 | 화면 좌/우 버튼 (탭 + 홀드 repeat) + 키보드 보조 |
| 종료 조건 | HP 소진만 (목표 클리어·시간제한 모드는 Phase 2) |
| 스택 | Next.js + framer-motion, 정적 export |
| 화면 방향 | 세로 고정 |
| 배포 | 개인 프로젝트 → 추후 웹뷰 탑재 (대응 모듈 선반영) |
| 사운드 | 미포함 |
| 랭킹 | 로컬 최고 점수만 |
| 다국어 | 스펙 아웃 |

## 1. 컨셉

동물의 숲 무드(파스텔·둥근 형태·따뜻한 조명)의 캐주얼 낙하물 받기 게임.
머리 위에 바구니를 얹은 **다람쥐**를 레인 사이로 옮기며, 떨어지는 **과일**을 **레시피 순서대로** 받는다.

핵심 스킬은 반사신경이 아니라 **"오답을 피해 정답 레인까지 가는 경로와 타이밍 판단"** 이다.
