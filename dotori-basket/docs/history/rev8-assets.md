# rev8 — 미제작 7종 제작 · 아이템 폴더 재편 (2026-09-15)

## 발단

Lv6 이후에서 레몬·파인애플 등이 전부 **액박**으로 떨어졌다.

원인은 두 가지가 겹쳐 있었다.

1. `items.ts`가 16종을 정의하는데 실제 그림은 8종(체리까지)뿐이었다.
2. 컴포넌트가 **하드코딩된 파일명 목록**으로 `src`를 조립했다. 목록에 없는 id는
   조용히 깨진 경로가 됐고, 타입도 테스트도 이를 잡지 못했다.

## 조치

### 아트 7종 — 손으로 그렸다

레몬 · 파인애플 · 복숭아 · 블루베리 · 아보카도 · 키위 · 자몽.
생성 도구는 쓰지 않았다(`mini-games/CLAUDE.md`). 기존 SVG에서 실측한
`#46200E` · stroke-width 2.4 · 100 뷰박스 · 영역당 단일 톤을 그대로 따랐다.

둥근 계열이 이미 많아 **48px에서 구분되는지**가 판정 기준이었다. 원형 3종은
질감으로 갈랐다 — 키위는 갈색 솜털 림, 자몽은 방사형 조각, 복숭아는 세로 골.

> 아보카도는 두 번 다시 그렸다. 1차는 비틀린 조롱박, 2차는 씨가 과육을 삼켰다.
> 3차(서양배 실루엣 · 껍질 `#4E7346` / 과육 `#CFE0A4` / 씨 `#9C7247` r=12.5)가 통과.

### 「사과 단면」 삭제 — 15종 + 방해물 2종

사과와 같은 그림을 쓸 수밖에 없는데, 그러면 레시피가 «사과»를 요구할 때
둘 중 무엇을 받아야 하는지 **화면에서 구분이 불가능**하다. 게임이 성립하지 않아 뺐다.

### ⭐ 경로를 데이터로 — `ItemDef.sprite`

컴포넌트의 조립을 없애고 `items.ts`가 경로를 들게 했다. `srcOf(d) => d.sprite`.
`items.test.ts`가 ①파일 존재 ②중복 없음 ③폴더와 정확히 일치를 강제한다 —
아트가 없는 아이템을 추가하면 **테스트가 먼저 깨진다.**

### ⭐ 폴더를 계보에서 역할로

`game/`(SpriteCook 트림본) · `authored/`(손작업)로 갈라 뒀었다. 손작업이 5종일 때는
읽혔지만 12종이 되자 **「이 과일 아트가 있나」에 두 폴더를 뒤져야** 했다.

```
public/assets/items/   아이템 17종 — 이 폴더가 곧 보유 현황
public/assets/scene/   다람쥐 · 배경 2장
```

계보는 확장자가 말한다: `.png` 5종은 생성물 트림본(생성 금지라 더 늘지 않는다),
`.svg`는 실측으로 직접 그린 것. 재측정 가능 여부가 갈리므로 여전히 구분은 필요하지만,
**그 구분은 폴더가 아니라 파일명이 지는 게 맞다.**

프로토타입(동결)의 경로도 함께 고쳤다 — 로직 변경이 아니라 기계적 치환이다.
