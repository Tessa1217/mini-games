# 폐기 — 2D 수채 방향

## 12. 아트 방향 확정 — 2D 수채

시안 비교 결과 **선 없는 수채 방향**으로 확정했다.

| | 채택 |
|---|---|
| 매체 | **2D 수채** — 윤곽선 없이 색면으로 형태를 만든다 |
| 질감 | 가장자리가 물감처럼 번진다 (`feTurbulence` + `feDisplacementMap` + 미세 블러) |
| 렌더 | **2D 스프라이트 + DOM/CSS transform** → three.js 불필요 |

### 12-1. 렌더 전략에 미치는 영향

2D 스프라이트도 **평면 회전은 자유롭다.** 떨어지는 과일이 도는 연출은 CSS `transform: rotate()`로 충분하다.
잃는 것은 "회전할 때 빛이 표면을 따라 움직이는 것" 하나뿐이다.

→ **three.js를 넣지 않는다.** `PLAN.md` rev.5 §6(DOM + CSS transform · framer-motion은 연출 전용)이
원래 설계 그대로 유효하고, 번들 **116 KB(gzip)** 를 아낀다.

### 12-2. 선이 없어서 생기는 제약

선이 형태를 붙잡아주지 않으므로 **실루엣이 유일한 구분 수단**이 된다.
§4의 형태 축을 3D 시안보다 **더 강하게** 지켜야 하고, 특히 방해물 2종은
**채도를 과일보다 확실히 낮춰** 색으로도 한 번 더 갈라놓는다.
