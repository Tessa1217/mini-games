# 에셋 제작 절차

새 에셋은 **생성 도구를 쓰지 않고**, 기존 에셋에서 실측한 수치로 벡터를 직접 그린다.

## 계보 — 어떤 파일이 어디서 왔나

| 디렉터리 | 내용 | 계보 | 재측정 |
|---|---|---|---|
| `assets/generated/` | SpriteCook 원본 7장 (1024px) | 생성물. 배포 가능 | **기준값 출처 — 지우지 않는다** |
| `assets/game/` | 실사용 PNG/JPG 8개 | `generated/`를 128px로 트림·축소 | 가능 (원본이 있다) |
| `assets/authored/` | 수박·배·체리·돌멩이·나뭇가지 SVG | 손으로 그린 베지에 | **불가 — 실물 SVG가 유일 기준** |

`assets/game/bg-forest-full.jpg`만 예외로, `generated/bg-forest.png`에서 나무를 잘라 조립한
합성물이다(아래 참조).

## 새 아이템을 그릴 때

1. **기준값을 실측한다** — 기존 스프라이트에서 뽑는다. 눈대중으로 정하지 않는다.
   ```
   윤곽선  #46200E · stroke-width 2.4   (assets/authored/*.svg 5개 실측)
   채색    영역당 단일 톤. 그라데이션·명암층 없음
   잎      #7E8C70
   ```
2. **실루엣을 먼저 정한다.** 기존 세트와 겹치지 않는 형태인지 본다 — 원형 계열이 이미 많다.
   방해물은 과일과 확실히 갈라야 한다(돌멩이=납작한 각진 덩어리, 나뭇가지=긴 대각선).
3. 100 × 100 뷰박스에 그린다. `stroke-linejoin`/`linecap`은 `round`.
4. **48px에서 확인한다.** 크게 보면 다 그럴듯하다 — 판정은 실제 게임 크기에서 난다.
5. **흑백으로 한 번 더 본다.** 배경 대비는 `art/silhouette.md`의 림 규칙을 따른다.

## 배경을 다시 조립할 때

게임 배경(`bg.jpg`)은 좌우 끝에만 나무가 있고 가운데가 비어 있다 — 낙하 경로에 장식이 있으면
안 되기 때문이다. 화면 오버레이용 숲길(`bg-forest-full.jpg`)은 여기서 조립했다.

1. 왼쪽 나무는 **줄기 바로 오른쪽에서 프레임에 잘려** 있다(줄기 x 0~31).
   `x=0`에서 미러링하면 줄기 하나짜리 온전한 나무가 복원된다.
2. 하늘(`#C4E1F4`)과 잔디가 단색이므로, 수평선 위/아래로 기준색을 나눠 키잉하면 나무만 떨어진다.
3. 뒤쪽 줄은 0.62~0.72배로 줄이고 **하늘색을 18% 섞어** 공기원근을 준 뒤 앞쪽 줄을 겹친다.
4. 잔디·수평선은 **중앙에서만** 뗀다 — 가장자리를 쓰면 원본 나무 밑동이 딸려 온다.
5. 타일은 **미러 타일링**(홀수 칸을 뒤집기)으로 이어 붙여 경계 행·열을 일치시킨다.
