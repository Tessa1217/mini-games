# 접근성 체크리스트

## 7. 접근성 체크리스트

- [ ] 좌/우 컨트롤은 실제 `<button>` — 키보드 포커스·스크린리더 대응 (`aria-label="왼쪽으로"`)
- [ ] 아이템은 색 + **형태 + 크기** 3중 구분 (`art/silhouette.md`)
- [ ] 텍스트 대비: `--ink`(#5A4632) on `--cream`(#FFF6E3) = **8.9:1** ✅ AAA
- [ ] 점수/HP 변화는 시각 + `aria-live="polite"` 병행
- [ ] `prefers-reduced-motion` 대응 (`arch/stack.md`)
- [ ] 터치 타깃 최소 44×44 (컨트롤은 72×72)
- [ ] 포커스 링: `outline: none` 시 대체 스타일 필수 — `--accent` 3px 링
