# 무드와 타이포

## 0. 무드 원칙 — 동물의 숲

| 원칙 | 구체적으로 |
|---|---|
| **순수 검정을 쓰지 않는다** | 텍스트·아웃라인 모두 따뜻한 브라운 계열(`#5A4632`). 검정은 이 무드를 즉시 깬다 |
| **채도를 낮춘다** | 원색 금지. 모든 색이 약간 바랜 듯한 톤 |
| **모서리를 둥글게** | 직각 없음. 카드 16px, 칩 10px, 버튼 원형 |
| **그림자는 갈색 알파** | `rgba(90,70,50,.12)` — 회색 그림자는 차갑게 읽힌다 |
| **선이 아니라 면** | 굵은 아웃라인 대신 면과 부드러운 명암으로 형태를 만든다 |
| **움직임은 탄성** | 선형 이징 금지. 모든 전환에 약한 오버슈트 |

## 3. 타이포

| 용도 | 서체 | 크기/굵기 |
|---|---|---|
| 점수·레벨·배너 | **Jua** (Google Fonts, 둥근 한글) | 점수 22 / 배너 28 |
| 라벨·본문 | Pretendard → 시스템 폴백 | 13~15, 500 |
| 숫자 강조 | Jua | `font-variant-numeric: tabular-nums` 필수 |

점수는 매 획득마다 바뀌므로 **tabular-nums가 없으면 숫자 폭이 흔들려 덜컹거린다.**

## 10. 아트 방향

파스텔, 채도 낮은 초록·크림·우드, 둥근 실루엣, 굵은 아웃라인 없음.
다람쥐는 대기/이동/피격/환호. 배경은 숲 레이어 2~3장 아주 느린 패럴랙스.

**과일은 실루엣만으로 구분 가능해야 한다** — 8종까지 늘어나는데다 색각 이상 대응도 겸한다.
방해물은 과일과 확실히 다른 실루엣(각진 형태·어두운 톤)으로 즉시 구분되게.

**초기엔 도형·이모지 플레이스홀더로 로직부터 완성한다.** 렌더 레이어를 분리해두면
에셋 대기 때문에 로직 개발이 막히지 않는다.
